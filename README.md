# Inmobiliaria Hogar Ideal

Página web de una sola página para una inmobiliaria, hecha solo con HTML, CSS y un poco de JavaScript. No necesita instalar nada.

## Características

- Diseño adaptable (computador, tablet y celular)
- Menú fijo con navegación suave entre secciones
- Sección de propiedades destacadas con tarjetas
- Formulario de contacto con mensaje de confirmación
- Año del pie de página actualizado automáticamente

## Estructura

```
.
├── index.html   # Página completa (HTML + CSS + JS)
└── README.md
```

## Cómo usarla

1. Descarga `index.html`.
2. Ábrelo con doble clic en tu navegador.

## Personalización

- **Nombre y logo:** busca `Hogar Ideal` en `index.html` y cámbialo.
- **Colores:** edita las variables en `:root` (`--primario`, `--oscuro`).
- **Propiedades:** copia y modifica un bloque `<div class="propiedad">`. Puedes cambiar el emoji de `.foto` por una imagen con `<img>`.
- **Formulario:** ahora solo muestra un mensaje. Para recibir los datos realmente, conéctalo a un servicio como Formspree o a tu propio backend.

Sube la carpeta a GitHub Pages, Netlify o Vercel.
